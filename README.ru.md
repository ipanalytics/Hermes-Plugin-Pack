## Обзор

Hermes-Plugin-Pack предоставляет важные плагины для Hermes Agent, расширяющие функциональность и возможности эксплуатации. Пакет содержит четыре основных плагина: журнал обратной связи, фабрика навыков, песочница proot и компактное представление контекста. Эти плагины решают общие задачи в работе агента, разработке и изоляции безопасности.

## Архитектура

Пакет плагинов следует архитектуре плагинов Hermes Agent, где каждый компонент работает как самостоятельный модуль. Система обратной связи записывает взаимодействия пользователей и реакции систематически. Фабрика навыков позволяет быстро создавать и итерировать навыки. Песочница proot обеспечивает безопасную среду выполнения для ненадежного кода. Компактное представление управляет размером контекста, сохраняя критические детали через алгоритмы выбора Jev.

Каждый плагин интегрируется с основными системами Hermes Agent через стандартизованные интерфейсы. Система обратной связи подключается к потокам бесед. Фабрика навыков соединяется с системой управления навыками. Плагин песочницы управляет контейнерным выполнением. Плагин компактности работает во время переходов контекста.

## Возможности

- **Журнал реакций.** Плюс или минус из интерфейса чата становится строкой в `$HERMES_HOME/data/feedback.jsonl` вместе с сообщением, на которое отвечал, — у разбора появляется свидетельство вместо памяти.
- **Песочница без root.** `proot-sandbox` делает терминальный бэкенд работающим под proot: `/workspace` доступен на запись, а домашний каталог, где лежат секреты, память и история сессий, не смонтирован вовсе.
- **Сжатие вырезанием, а не пересказом.** `jev_compact` оценивает каждый вызов инструмента и убирает устаревшие; всё оставшееся остаётся дословно, потому что пересказ тихо врёт про пути, числа и ошибки.
- **Навыки из сессии.** `skill-factory` смотрит за работой через `post_tool_call` и предлагает повторяющуюся часть как навык, чтобы следующая сессия начиналась с процедуры, а не с расшифровки.
- **Отказ, который деградирует, а не ломается.** Если модель решений недоступна, сжатие откатывается на детерминированную вырезку; если нет proot, плагин сообщает об этом, а не выполняет команду молча без песочницы.
## Быстрый старт

Плагины — это каталоги, а не пакет: хост загружает плагин из `$HERMES_HOME/plugins/<имя>` и включает его по имени в `plugins.enabled`. Шага установки нет, потому что устанавливать нечего.

```bash
git clone https://github.com/ipanalytics/Hermes-Plugin-Pack.git
mkdir -p "$HERMES_HOME/plugins"
cp -r Hermes-Plugin-Pack/plugins/* "$HERMES_HOME/plugins/"
```

```yaml
# config.yaml
plugins:
  enabled:
    - feedback-reactions
    - proot-sandbox
    - skill-factory
    - jev_compact
```

Список читается при запуске, поэтому изменение вступает в силу после перезапуска шлюза.

## Установка

| Плагин | Вид | Что нужно |
| --- | --- | --- |
| `feedback-reactions` | standalone | интерфейс, который присылает реакции |
| `proot-sandbox` | backend | `proot` в `PATH` (`apt-get install proot`), Hermes 0.21 или новее |
| `skill-factory` | standalone | ничего |
| `jev_compact` | context-engine | `TYPESAFE_API_KEY` в окружении |

Каталог плагина содержит манифест (`plugin.yaml`), код (`__init__.py`), свой README и, если он есть, вспомогательный модуль. Установка — копирование, включение — строка в конфиге, удаление — то же в обратную сторону. Нужен Python 3.11 или новее.

## Использование

Каждый плагин проявляется через хост, поэтому точки входа принадлежат хосту, а не отдельной команде.

| Плагин | Хук или роль | Что происходит |
| --- | --- | --- |
| `feedback-reactions` | `gateway_platform_event` | Реакция добавляет строку в `$HERMES_HOME/data/feedback.jsonl`. |
| `proot-sandbox` | терминальный бэкенд | Команды идут под proot: `/workspace` доступен на запись, `$HERMES_HOME` не смонтирован. |
| `skill-factory` | `post_tool_call` | Смотрит за сессией и предлагает повторяющуюся часть как навык через `/skill-factory-propose`. |
| `jev_compact` | движок контекста | Сжимает промпт при переходе через `threshold_tokens`, вырезая устаревшие результаты инструментов вместо их пересказа. |

Свои параметры плагин объявляет в `plugin.yaml` в разделе `config_schema`, значения передаёт хост.

| Плагин | Параметр | Значение |
| --- | --- | --- |
| `jev_compact` | `threshold_tokens` | Сжимать, когда промпт дошёл до стольких токенов (по умолчанию 250000). |
| `jev_compact` | `protect_first_n`, `protect_last_n` | Сообщения в начале и конце, которых сжатие не касается. |
| `jev_compact` | `drop_probability` | Порог вероятности, выше которого отвеченный вызов инструмента вырезается (по умолчанию 0.75). |
| `proot-sandbox` | `workspace` | Каталог хоста, монтируемый как `/workspace`. |
| `proot-sandbox` | `scratch_home`, `scratch_tmp` | Каталоги, монтируемые как домашний каталог песочницы и `/tmp`. |

## Выводы/Артефакты

Плагины генерируют несколько типов артефактов. Система обратной связи создает лог-файлы в формате JSON. Фабрика навыков производит новые файлы навыков с правильной структурой. Песочница создает временные каталоги выполнения. Плагин компактности генерирует сокращенные представления контекста, сохраняя важную информацию.

Все артефакты следуют последовательным соглашениям об именовании и хранятся в назначенных каталогах в рабочем пространстве Hermes.

## Конфигурация

Параметры конфигурации для каждого плагина:

| Ключ | Тип | Описание |
|-----|------|-------------|
| feedback.enabled | boolean | Включить отслеживание реакций обратной связи |
| feedback.log_path | string | Путь для логов обратной связи |
| skill_factory.template_dir | string | Каталог для шаблонов навыков |
| proot.sandbox_enabled | boolean | Включить функциональность песочницы proot |
| proot.max_memory | string | Ограничение памяти для процессов в песочнице |
| proot.timeout | integer | Таймаут выполнения в секундах |
| compaction.enabled | boolean | Включить компактность контекста |
| compaction.target_size | integer | Целевой размер контекста в токенах |

Настройте ротацию логов обратной связи в производственных средах. Мониторьте производительность песочницы и при необходимости корректируйте ограничения.

Плагин компактности требует достаточной памяти для эффективной обработки больших контекстов. Планируйте хранилище для сгенерированных артефактов и логов в соответствии с ожидаемыми моделями использования.

## Объем проекта

Этот проект включает четыре функциональных плагина для Hermes Agent: журнал обратной связи, фабрика навыков, песочница proot и компактное представление. Он не включает пользовательские модели, компоненты интерфейса или интеграции внешних сервисов сверх стандартных интерфейсов Hermes Agent. Объем исключает решения песочницы для Windows или macOS.

## Сценарии использования

- Команды разработчиков, использующие Hermes Agent, которым необходимы шаблонирование и управление навыками
- Организации, требующие безопасных сред выполнения кода для задач агента
- Пользователи, стремящиеся к подробному отслеживанию обратной связи для взаимодействий с агентом
- Системы, требующие управления контекстом для длительных бесед
- Команды, внедряющие Hermes Agent в продакшен со строгостями безопасности

## Ограничения

- Функциональность песочницы ограничена системами Linux с поддержкой proot
- Точность компактности контекста зависит от доступных ресурсов памяти
- Логирование обратной связи может генерировать большие объемы данных в активных развертываниях
- Некоторые плагины требуют повышенных привилегий для полной функциональности
- Ограниченная совместимость со старыми версиями Python ниже 3.11

## Развертывание

```bash
git clone https://github.com/ipanalytics/Hermes-Plugin-Pack.git
cp -r Hermes-Plugin-Pack/plugins/* "$HERMES_HOME/plugins/"
# добавить имена в plugins.enabled в config.yaml и перезапустить шлюз
```

Проверка здесь поведенческая, потому что пинговать нечего: отправить реакцию и прочитать строку в журнале, выполнить команду и убедиться, что домашний каталог внутри песочницы не виден, перейти порог токенов и прочитать `$HERMES_HOME/data/jev_compact_decisions.jsonl`.

Откат — обратная сторона установки: убрать имя из `plugins.enabled` и удалить каталог. Журнал и журнал решений — обычные файлы в `$HERMES_HOME/data/` и переживают и то и другое.
